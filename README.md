# OWID Datasets

> [!IMPORTANT]
> This repository has not been update in some time, and has therefore been archived.
> There are new ways to obtain chart data and metadata:
> - [Our Chart API](https://docs.owid.io/projects/etl/api/chart-api/), which lets you programmatically access and download the data used in any chart
> - [Improved data downloads](https://ourworldindata.org/easier-to-reuse-our-data), which do the same directly from the chart interface
> - [ETL](https://docs.owid.io/projects/etl/getting-started/), our custom tool that processes and injects data sources into our vast database

This is an ongoing collection of datasets with source information in CSV+datapackage format, exported automatically from the ourworldindata.org database. Most datasets included here are annual time series data for social and economic indicators by country.

The repository covers mainly smaller datasets which have been individually uploaded and annotated with source information by OWID authors.
